## 🚀 How to Run

1. Install Python 3 from [python.org](https://www.python.org/downloads/).
2. Clone this repository:

   ```bash
   git clone https://github.com/sumitanjana13/python-foundation.git
   cd python-foundation
   ```

3. Open the folder in VS Code and run any `.py` file:

   ```bash
   python 01_python_basics/hello_world.py
   ```
